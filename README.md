# 云融（YunRong）— 企业协作终端

跨平台企业办公协作桌面客户端，以即时通讯为核心，融合任务通知与文件传输。

> **当前阶段**：设计文档撰写中（Phase 0）。详见 [ENGINEERING.md](ENGINEERING.md)。

## 技术栈（设计）

| 层 | 技术 |
|----|------|
| 桌面 GUI | Qt 6 Widgets (C++17) |
| 客户端网络 | QWebSocket + QNetworkAccessManager |
| 客户端存储 | SQLite 3 |
| 后端服务 | Go (Gin + gorilla/websocket) |
| 后端存储 | PostgreSQL 14+ |
| 构建 | CMake 3.20 + Go modules |
